Questions

Is it really free?

Yes. No paid tier, no subscription, no account. The code is open source under the MIT license.

How do I get Canvas deadlines on my desktop?

In Canvas open Calendar → Calendar Feed and copy the link. In UMST pick Connect a Service → Canvas and paste it.

Does it work with Google Calendar and Gmail?

Yes. Add your Google account in System Settings → Internet Accounts with Calendars on, and it shows up, invites from Gmail included.

What's Show Desktop?

A separate menu bar app by @stanczykwyatt that hides every window in one click so you can see your desktop, and your calendar. The install command adds it. To skip it, put SHOW_DESKTOP=0 before zsh in the command.

macOS says it's from an unidentified developer?

UMST isn't notarized by Apple yet. The install command handles it. If you download the .zip, open System Settings → Privacy & Security → Open Anyway once.
